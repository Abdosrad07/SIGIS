# Roadmap backend

- Fondations : health, CORS, DRF, modèles, tests.
- Authentification : utilisateurs, rôles, sessions ou tokens.
- Admissions/dossiers : serializers, vues, permissions.
- Documents : stockage et validation.
- UE/inscriptions : règles d’unicité et intégrité.
- Notes/relevés : calculs et exports.
