# Roadmap frontend

- Fondations : routes, layout, client API, mocks.
- Authentification : session, garde de route, profil.
- Admissions/dossiers : formulaires, listes, états.
- Documents : téléversement et affichage.
- UE/notes : listes, filtres, saisie.
- Relevés/tableau de bord : visualisation et tests.

Les développeurs peuvent démarrer sur le shell, les pages placeholder, les mocks ou les composants sans attendre le backend.
